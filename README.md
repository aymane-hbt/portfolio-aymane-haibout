📁 Portfolio-Website – Aymane Haibout
Eine persönliche Portfolio-Website, entwickelt als Teil meiner Bewerbung um eine Ausbildung als Fachinformatiker. Sie zeigt meine technischen Fähigkeiten, aktuelle Projekte und Kontaktmöglichkeiten – alles in einem modernen, responsiven Layout.

🔗 Live-Demo: https://haibout-portfolio.vercel.app/

🛠️ Technologien
Next.js – React Framework für Performance und serverseitiges Rendering

React & TypeScript – Komponentenbasiert & typsicher

Tailwind CSS – Schnelles und konsistentes Styling

shadcn/ui – Wiederverwendbare, moderne UI-Komponenten

Vercel – Deployment-Plattform mit CI/CD

✨ Features
Responsives Design – Optimiert für Desktop, Tablet und Smartphone

Dark/Light Mode – Umschaltbar mit einem Klick

Projektgalerie – Übersicht meiner Entwicklungsarbeiten

Modulare Komponentenstruktur – Übersichtlich und erweiterbar

Navigation & Kontaktbereich – Einfach, klar und benutzerfreundlich
